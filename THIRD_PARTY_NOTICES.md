# Peeping Tom reference

The PTOM feature was implemented on 26 October 2026 using the requested behavior of the supplied **Peeping Tom 1.7.13** project as a reference.

- Upstream author: **ascclemens** (Anna Clemens).
- Upstream repository recorded in the supplied project: https://git.annaclemens.io/ascclemens/PeepingTom
- Supplied upstream licence: **European Union Public Licence v. 1.2**. Its complete, unmodified text is retained at `LICENSES/PeepingTom-EUPL-1.2.txt`.

PlayerTrack's collector, session-history model, tab and overlay are newly implemented for the current Dalamud API. The original PlayerTrack MIT licence and copyright notices remain intact.

Since 3.7.8.0, `PlayerTrack.Plugin/Resource/PtomTarget.wav` is the unchanged `Peeping Tom/Resources/target.wav` from the supplied Peeping Tom project. It is embedded as the optional PTOM targeting sound and is attributed to that project and its author above, under the supplied EUPL 1.2 licence retained in `LICENSES/PeepingTom-EUPL-1.2.txt`. The supplied source archive is retained locally as `reference/PeepingTom-main.zip`; upstream is linked above. No Peeping Tom source code or assemblies are bundled.
